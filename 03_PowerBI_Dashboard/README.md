# Power BI – E-commerce Customer Analytics Dashboard

## 1. Project Overview

This is the third stage of my E-commerce Customer Analytics project. In this stage, I developed an interactive Power BI dashboard to analyze customer purchasing behaviour, revenue performance, customer retention, and RFM segmentation.

The dashboard uses the processed dataset generated during the Python Pandas analysis stage.

## 2. Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Interactive Visualizations
- Bookmarks and Buttons

## 3. Dashboard Features

### Business Overview
- Total Customers
- Total Revenue
- Customer Churn Percentage
- Average Customer Value
- Revenue by Customer Segment
- Monthly, Quarterly, and Yearly Revenue Trends
- Interactive filters for Month, Quarter, Year, Country, Segment, and Churn Status

### RFM Analysis
- Segment Performance Summary
- Country Performance Summary
- Average Customer Value by Segment
- Top 5 Countries by Average Customer Value
- Customer Churn Trends
- RFM Score Analysis

## 4. Key Power BI Concepts Applied

- Data Import and Transformation using Power Query
- DAX Measures and Calculated Columns
- KPI Cards
- Matrix Visualizations
- Bar and Line Charts
- Slicers and Filters
- Bookmarks and Buttons
- Conditional Formatting
- Interactive Dashboard Navigation

## 5. Business Objectives

- Understand customer purchasing patterns.
- Identify high-value and at-risk customer segments.
- Monitor revenue and customer performance.
- Analyze customer retention and churn.
- Support data-driven business decisions.

## 6. Project Workflow

**SQL Data Cleaning → Python Pandas & RFM Analysis → Power BI Dashboard**
